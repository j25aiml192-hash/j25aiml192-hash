## ⚡ SELECTED WORK

<sub>not everything I've built — just the ones worth talking about.</sub>

<br>

### 💸 Spendly
**AI-powered SaaS spend intelligence.**

A platform for discovering SaaS subscriptions, analysing seat utilisation, detecting duplicate tools, forecasting renewals, scanning invoices, and surfacing AI-assisted savings opportunities.

`React` · `Express` · `MongoDB` · `Groq`

[View repository →](https://github.com/j25aiml192-hash/spendly)

---

### 🪙 VielFi
**Wallet-connected lending.**

A lending platform built around borrower and lender workflows, onboarding, loan creation, discovery, dashboards, profiles, circles, notifications, and wallet connectivity.

`React` · `Vite` · `ethers`

[View repository →](https://github.com/j25aiml192-hash/vielfi)

---

### 🕸️ NEXUS — SIH
**Predictive intelligence for cybercrime investigations.**

A system that turns fragmented complaint and financial evidence into an intelligence layer using graph-based analysis, fraud-risk scoring, spatial prediction, H3 mapping, explainability, and operational alerts.

`FastAPI` · `React` · `ML` · `Graph Intelligence`

[View repository →](https://github.com/j25aiml192-hash/nexus-SiH)

---

### 🏛️ NitiSetu
**AI-powered governance intelligence.**

A command centre for citizen complaints — combining AI classification, semantic clustering, SLA monitoring, department analytics, geographic monitoring, and decision support.

`Next.js` · `FastAPI` · `PostgreSQL` · `Gemini`

[View repository →](https://github.com/j25aiml192-hash/nitisetu-frontend)

---

### 🤖 Jorvis
**A desktop AI assistant built as a system.**

An exploration into wake-word detection, speech recognition, LLM reasoning, tool execution, text-to-speech, desktop controls, and persistent memory.

`Python` · `LLMs` · `Deepgram` · `SQLite`

[View repository →](https://github.com/j25aiml192-hash/jorvis)
